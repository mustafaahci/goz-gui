# Keyboard shortcuts

goz-gui's default keys, most of them Everything's. Back to the [README](../README.md); every feature in detail is in the [feature reference](FEATURES.md).

## Main window

| Key | Action |
| --- | --- |
| Type | Search (goz query syntax: `*.pdf`, `C:\Users\ report`, `ext:jpg dm:lastweek`, `size:>1mb`…) |
| Enter (search box) | Select the result opened most often (the top one when none of them was opened before); Enter again opens the selection |
| Up / Down / PgUp / PgDn (search box) | Move through the results while typing (Shift extends the selection, Ctrl moves the focus only) |
| Tab / Shift+Tab | Move between the search box and the results (and the panes that are tab stops) |
| Ctrl+T / Ctrl+W (or Ctrl+F4) | New tab / close the tab (the last one closes the window) |
| Ctrl+Tab / Ctrl+Shift+Tab | Next / previous tab (with one tab, as Tab / Shift+Tab) |
| Ctrl+Shift+T | Reopen the tab closed last |
| Ctrl+N / Ctrl+Shift+W | New window / close the window |
| F6 / Shift+F6 | Next / previous frame: the search box, the panes, the results |
| Shift+Esc | Close the pane that has the keyboard |
| Alt+P | Show or hide the preview pane (View → Preview) |
| Alt+Down / Alt+Up | Search history (Up/Down, Enter to use, Delete to forget, Esc) |
| Alt+Up (outside the search box) | Up one folder: the Folders pane's folder's parent (from a drive, no folder) |
| Ctrl+H / Ctrl+Shift+H | Find search history / organize search history |
| Enter / Shift+Enter / double-click | Open (more than 32 items asks first) |
| Ctrl+Enter, double-click in the Path column | Open the containing folder with the items selected, one window per folder |
| Ctrl+Shift+Enter | Run as administrator |
| Alt+Enter | Properties (one sheet for several items) |
| Ctrl+C / Ctrl+Insert, Ctrl+X | Copy / cut the selected files, to paste in Explorer |
| Ctrl+V / Shift+Insert | Paste the files on the clipboard into the selected folder (or the folder of the selected file); a copy pasted into its own folder is named "name - Copy", as in Explorer |
| Delete / Shift+Delete | Delete the selection to the Recycle Bin / for good (Windows asks first) |
| F2, or a slow second click on a name | Rename in place (Enter or a click elsewhere keeps it, Esc cancels; the slow click not with one-click opening); with several rows selected, Advanced Rename |
| Shift+F2 | Advanced Rename (the results) |
| Ctrl+Z or Alt+Backspace / Ctrl+Y (the results) | Undo / Redo the last file operation goz-gui did |
| Ctrl+Shift+Z | Undo History |
| Ctrl+Shift+C | Copy full path |
| Ctrl+A | Select all |
| F4 / Shift+F4 | Move to the next / previous selected result |
| Alt+D, Ctrl+E, Ctrl+L / Esc | Back to the search box |
| Ctrl+F | Find in the results (the find bar) |
| F3 / Shift+F3 | Find next / previous |
| Ctrl+G | Go to a result by its number |
| F2 (search box), right-click the search box | Advanced Search / the search box's menu |
| Ctrl+Shift+K | Organize filters |
| F11 | Fullscreen |
| Alt+1 / 2 / 3 / 4 | Window size: small, medium, large, fit to the columns |
| Ctrl+1 / 2 / 3 / 6 | Sort by name / path / size / date modified (again to reverse) |
| Ctrl+I / Ctrl+U | Match case / match path |
| Alt+Left / Alt+Right, mouse back / forward | Previous / next search, with its options and sort |
| Alt+Home | Home: the empty search by default (see Settings) |
| Ctrl+D / Ctrl+B / Ctrl+Shift+B (or Ctrl+Shift+O) | Add to bookmarks / find a bookmark / organize bookmarks |
| Ctrl+J | Run history |
| Ctrl+O | Open a file list (File → Open File List...) |
| Right-click a result, Shift+F10, Apps key | The row menu; with Shift held, Explorer's extended verbs too |
| F5 | Refresh |
| Ctrl+Backspace / Ctrl+Delete | Delete the previous / next word in the search box |
| F1 / Ctrl+F1 | goz help / about goz-gui |
| Ctrl+Shift+Q | Exit |

These are the defaults: Options → Keyboard gives any command other keys or none (see [Customization](FEATURES.md#customization-fonts-colours-keys-scale)), and the menus show the keys in force.

## More keys

| Key | Action |
| --- | --- |
| Ctrl+Shift+1 / 2 / 3 | Extra large / large / medium thumbnails |
| Ctrl+Shift+6 | Details (rows and columns) |
| Ctrl+= / Ctrl+- / Ctrl+0, Ctrl+mouse wheel | Zoom in / zoom out / back to 100 % |
| Ctrl+] / Ctrl+[ | Next / previous filter |
| Ctrl+Num + | Size all columns to fit |
| Ctrl+S | Export the results |
| Ctrl+P | Options |
| Alt+A / Alt+C (find bar) | Highlight All / Match Case |
| Ctrl+click or F2 on a file-list term (search box) | Edit File List Slot (F2 elsewhere in the box is Advanced Search) |
| Ctrl+Space (Advanced Rename's formats) | List what can go in the format |
| Ctrl twice (Options → UI → Double Ctrl) | Show, new or toggle window, when an action is chosen (off by default) |

## File List Editor

| Key | Action |
| --- | --- |
| Ctrl+N / Ctrl+O | New / open a list |
| Ctrl+S / Ctrl+Shift+S | Save / save as |
| Ctrl+W | Close the list |
| Ctrl+V | Paste files copied in Explorer, or names as text |
| Del | Remove the selected rows |
| Ctrl+A | Select all |
| Esc | Stop adding |
